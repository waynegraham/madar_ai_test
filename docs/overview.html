Evaluation against reviewed regions

Aggregate layout evaluation requires at least 5 paired pages for the same system and prompt, with complete layout review explicitly documented. This is a reporting threshold, not a guarantee of a representative or statistically sufficient sample.

Per-region-type evaluation is not yet available for a sufficient documented sample. Missing metrics are not zero scores.

No system currently has an eligible paired sample with documented complete layout review.

Evaluation scope, sample sizes, and exclusions

Each page is matched separately with the existing evaluator, using bounding-box IoU ≥ 0.5 and the same region type. True positives, false positives, and false negatives are pooled across the eligible pages before calculating rates; they are not averaged across pages.

Precision is the matched share of predicted regions; recall is the matched share of reference regions. F1 balances these two measures. Each row reports both region denominators, all paired pages, and the number of those pages containing a reference region of that type. A small type-specific sample still needs caution even when the overall page threshold is met.

Only a single corrected ALTO reference with no omitted unbounded blocks is eligible per page, and complete layout review must be explicitly documented in data/corpus.json. Partial or undocumented review cannot support false-positive counts. Multiple prediction records for the same system and prompt on a page are excluded from evaluation rather than silently choosing one. 0 ambiguous system–page combinations were excluded.

The inventory includes all readable prediction records, while the evaluation uses only eligible paired records. The reviewed-page count includes partial references and therefore may exceed evaluation coverage. HTR regions evaluated counts distinct linked reference regions with at least one computed CER/WER result, not the number of model readings.
