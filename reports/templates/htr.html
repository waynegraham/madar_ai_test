Transcription error measures against the human reference

Character error rate (CER) and word error rate (WER) compare each saved reading with the human transcription displayed above. Lower values indicate fewer edits relative to reference length; rates can exceed 100%. No Unicode, spelling, punctuation, diacritic, or line-break normalization is applied. CER compares Unicode code points; WER uses the existing evaluator’s whitespace splitting.

Transcription sources and comparison policy

Saved text is displayed without editorial correction, translation, or Unicode normalization. Line breaks are preserved. ALTO text is assembled in XML line order using the existing parser, with newlines between lines. Region associations use an explicit saved ID or a uniquely matching crop filename; ALTO associations require a stable ID or a unique reciprocal bounding-box match at IoU ≥ 0.95.

This display crop is generated from the current human region and original image. It does not reconstruct unrecorded inference settings or guarantee that historical crop boundaries were unchanged.
